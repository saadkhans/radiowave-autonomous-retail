# Hardware Experiments

This directory holds records of hardware characterization experiments (mmWave, RFID, CV) run
against the Foundation v0 contracts and simulator, per the phased plan in
[`docs/hardware/hardware-roadmap.md`](../hardware/hardware-roadmap.md).

Copy [`experiment-template.md`](./experiment-template.md) for each new experiment and name it
`YYYY-MM-DD-<short-slug>.md`. Fill in every section — an incomplete record is not useful for
replay comparison or regression tracking.

Never commit raw production captures or private data. See the template's intro for details.
